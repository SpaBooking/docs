## Before you start

Ask a SpaPortal administrator for an API key.

Keep the key private. It can access data for one or more configured companies.

## Send a request

Send the API key as a bearer token:

```bash
curl \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Accept-Language: cs_CZ,de" \
  "https://spaportal.cz/api/v1/hotels?max=10&offset=0"
```

The response contains localized fields for the languages you request.

## Use pagination

List endpoints return a limited number of items. Use `max` and `offset` to page through results.

```bash
curl \
  -H "Authorization: Bearer <API_KEY>" \
  "https://spaportal.cz/api/v1/visit-types?max=20&offset=20"
```

Read the `X-Total-Count` response header to get the total number of matching records.
