## Authenticate

### 1. Get your public key

Get a public key using the [authentication instructions](/api/authentication#getting-your-public-key).
The [channels and scope reference](/api/authentication#channels-and-scope)
explains which resources your key can access.

### 2. Use public key

Pass the public key in the `X-SpaPortal-Public-Key` header on every request:

```bash
X-SpaPortal-Public-Key: <your_public_key>
```

## Make your first request

The base URL for the v2 catalog is:

```text
https://spaportal.cz/api/v2
```

Fetch a list of hotels:

```bash
curl \
  -H "X-SpaPortal-Public-Key: <your_public_key>" \
  -H "Accept-Language: cs-CZ,de" \
  "https://spaportal.cz/api/v2/hotels"
```

**Example response (abridged):**

```json
{
  "data": [
    {
      "id": "66f16191f739705faa020001",
      "name": { "cs-CZ": "Lázně Aurora", "de": "Aurora Spa" },
      "stars": 4
    }
  ],
  "pagination": { "limit": 25, "nextCursor": null, "hasMore": false, "total": 1 }
}
```
