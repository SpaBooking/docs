SpaPortal is a hotel booking platform for spa stays and wellness packages.

It manages destinations, hotels, visit types, room availability, pricing, and
booking requests for public booking channels.

Use SpaPortal API when you connect an external booking client to that data.

## What you can build

With the public API, you can:

- List destinations, hotels, visit types, categories, tags, and loyalty
  programs.
- Read localized names and descriptions for booking forms.
- Check available dates, checkout dates, and prices.
- Create bookings through the public booking flow.

## API versions

API v1 is the current production API. Start with API v1 for live integrations.

API v2 is used for new public resources and breaking improvements. Review the
[API v2 design proposal](/api/v2/design) before depending on API v2 behavior.
