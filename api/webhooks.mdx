description: "Public webhook contract status for SpaPortal API integrations."

---

SpaPortal does not currently document a public webhook contract for API v1.

Build current integrations around synchronous API calls.

When SpaPortal exposes public webhook events, this reference will document:

- Event names
- Delivery URL setup
- Signature verification
- Retry behavior
- Example payloads
- Event-specific schemas

Do not rely on internal dashboard or scheduler behavior as a public webhook
contract.
