The API v2 base URL is:

```text
https://spaportal.cz/api/v2
```

The version is part of the URL path. Headers and query parameters do not
select a different API version.

## API coverage

| Resource | Status |
| --- | --- |
| Hotels, room types, and amenity dictionaries | Released |
| Visit types: catalog, package-at-hotel prices, and seasonal prices | Draft, not yet on the production API |
| Hotel `procedures` and the `hotel` reference in price minima | Draft, not yet on the production API |

Draft contracts are complete and marked as such on their pages. They are not
available on the production API until this table lists them as released.

Released endpoints follow the [compatibility policy](/guides/versioning#breaking-changes).
Draft contracts can change during review.
