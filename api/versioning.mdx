API v2 provides hotels, room types, and amenity dictionaries.
It does not yet replace the complete API v1 booking flow. Use the v2 reference
for endpoints available in v2, and [API v1](/api/v1) for visit types, final
pricing, and booking creation.

```txt
https://spaportal.cz/api/v2
```

API versions are explicit in the URL path — there is no version negotiation via headers or query parameters.

The two versions use different authentication headers, ID conventions, and
response shapes. A v2 `id` is not interchangeable with a numeric v1 request ID.
See the [booking flow](/guides/booking) for the v1 endpoint sequence.

Hotels, room types, and amenities follow the same
[versioning policy](/guides/versioning#breaking-changes). Breaking changes
require a new major API version.
