The API v2 base URL is:

```text
https://spaportal.cz/api/v2
```

The version is part of the URL path. Headers and query parameters do not
select a different API version.

## API coverage

| Resource | Status |
| --- | --- |
| Hotels, room types, and amenity dictionaries | Released |
| Visit types, package-at-hotel prices, and seasonal prices | Released |
| Hotel `procedures` and price minima naming the hotel | Released |

Every resource in this reference is released and follows the
[compatibility policy](/guides/versioning#breaking-changes). The
[changelog](/api/changelog) lists the changes of each release.
