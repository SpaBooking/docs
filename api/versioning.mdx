The current API version is **v2**. This documentation describes v2. All new integrations should use v2.

```txt
https://spaportal.cz/api/v2
```

API versions are explicit in the URL path — there is no version negotiation via headers or query parameters.

If you are looking for an older version, see the **Previous Versions** section.
