The API v2 base URL is:

```text
https://spaportal.cz/api/v2
```

The version is part of the URL path. Headers and query parameters do not
select a different API version.

## API coverage

| Resource | Status |
| --- | --- |
| Hotels and room types | Released |
| Amenity dictionary | Released |
| Visit types | Released |
| Indicative prices without capacity checks | Released |
| Price periods filtered by future permitted stays | Released |
| Per-person stay minimum in `priceFrom` | Released |
| Procedure assignments, photos, descriptions, and `expand=procedures` | Released |

The resources and features above are available. See
[Changes to API v2](/guides/versioning#changes-to-api-v2) for compatibility
guidance and the [changelog](/api/changelog) for release details.
