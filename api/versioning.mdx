The API v2 base URL is:

```text
https://spaportal.cz/api/v2
```

The version is part of the URL path. Headers and query parameters do not
select a different API version.

## API coverage

| Resource | Status |
| --- | --- |
| Hotels, room types and amenity dictionaries | Released |
| Visit types, hotel-pair prices and seasonal prices | Draft for integration review |
| Hotel procedures and the shared price minimum | Draft for integration review |

Draft pages describe the proposed contract and are marked accordingly.
Their presence in this reference does not mean the endpoints or fields are
available on the production API.

Released endpoints follow the [compatibility policy](/guides/versioning#breaking-changes).
Draft contracts can change during review.
