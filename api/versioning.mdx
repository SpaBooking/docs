The API v2 base URL is:

```text
https://spaportal.cz/api/v2
```

The version is part of the URL path. Headers and query parameters do not
select a different API version.

## API coverage

| Resource | Status |
| --- | --- |
| Hotels and room types | Released |
| Amenity dictionary | Released |
| Visit types | Released |
| Indicative prices without capacity checks | **Draft** |
| Price periods filtered by future permitted stays | **Draft** |

The resources above are released; the marked pricing changes are drafts.
API v2 is still in development,
so its contracts can change; see
[Changes to API v2](/guides/versioning#changes-to-api-v2). The
[changelog](/api/changelog) lists what each release made available.
