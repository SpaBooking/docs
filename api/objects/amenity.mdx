An entry nested in a category returned by
[`GET /api/v2/amenity-categories`](/api/v2/reference/amenity-categories/list-the-amenity-dictionary).
Its stable `code` identifies the amenity in hotel or room type responses. The parent
category object contains `scope` (`hotel` or `roomType`), the category code,
and its localized label. Identify a category by both `scope` and `code`.
`detailKinds` declares which structured fields can be populated on the
corresponding [Amenity value](/api/objects/amenity-value).

`notePlaceholder` is optional localized helper text for the amenity note. Most
amenities omit it.

## Detail kinds

`detailKinds` is metadata from the dictionary. Use it to decide which controls
to display and which fields on the corresponding hotel or room type amenity value carry
meaningful data. The values use snake case because they identify field groups,
not response property names.

An empty `detailKinds` array means that selecting the amenity is the complete
value. The corresponding hotel or room type amenity contains only its `code`.

For example:

```json
{
  "code": "sauna",
  "label": { "cs-CZ": "Sauna", "en": "Sauna" },
  "detailKinds": ["proximity", "access", "options", "opening_hours"],
  "options": [
    {
      "code": "finnish",
      "label": {
        "cs-CZ": "Finská sauna",
        "en": "Finnish sauna"
      }
    },
    {
      "code": "infrared",
      "label": {
        "cs-CZ": "Infra sauna",
        "en": "Infrared sauna"
      }
    },
    {
      "code": "steam",
      "label": {
        "cs-CZ": "Parní lázeň",
        "en": "Steam bath"
      }
    }
  ]
}
```

This sauna can populate `proximity` (and conditionally `proximityMeters`),
`access`, `options`, and `openingHours`. Because `detailKinds` includes
`options`, the entry carries an `options` array with every valid sauna choice.
The sauna does not support `note`, so the `note` property is omitted from its
[Amenity value](/api/objects/amenity-value).

## Room type example

<Warning>
  **Draft — room types:** This room-type contract may change until client
  integration is complete.
</Warning>

The `scope=roomType` dictionary describes a balcony as a presence-only amenity:

```json
{
  "code": "balcony",
  "label": { "cs-CZ": "Balkon", "en": "Balcony" },
  "detailKinds": []
}
```

The corresponding selected [Amenity value](/api/objects/amenity-value) is
`{ "code": "balcony" }`. Use this dictionary entry to resolve its label, or
request `expand=amenityLabels` on the room type.
