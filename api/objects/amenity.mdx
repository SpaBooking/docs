An amenity in the [amenity dictionary](/api/amenities#amenity-dictionary).
Hotel and room type responses reference it by `code`. See
[Detail kinds](/api/amenities#detail-kinds) for `detailKinds`.

An aquapark definition also lists `includedAmenityCodes`, the allowed facility
codes in scope `hotel`. See [Includes](/api/amenities#includes).
