<Warning>
  **Draft:** Procedures are returned by the visit type endpoints and in hotel
  `procedures`, which are not yet released on the production API. See
  [API coverage](/api/versioning#api-coverage).
</Warning>

A procedure is identified by `code` and carries a localized `label`, a
`category` with its own `code` and localized `label`, and `naturalSource`.
Labels follow [Localization](/api/localization); a missing translation is
`null`.

A hotel's [`procedures`](/api/objects/hotel#procedures) lists the procedures
it offers as plain Procedure objects. A package's
[treatment items](/api/objects/treatment#procedures) add `count` to the same
fields. Match the two by `code`.

```json
{
  "code": "carbon_dioxide_bath",
  "label": {
    "cs-CZ": "Kysličníková koupel",
    "de": "Kohlensäurebad"
  },
  "category": {
    "code": "hydrotherapy",
    "label": {
      "cs-CZ": "Vodoléčba",
      "de": "Hydrotherapie"
    }
  },
  "naturalSource": "carbon_dioxide"
}
```

## Natural sources

`naturalSource` is the natural healing source the procedure uses, or `null`
when it has none.

| `naturalSource` | Meaning |
| --- | --- |
| `carbon_dioxide` | Natural carbon dioxide |
| `peat` | Peat |
| `mineral_water` | Natural mineral water |
