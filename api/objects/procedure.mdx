<Warning>
  **Draft:** Procedure objects are proposed for visit type treatment items
  and the hotel's procedure offer. These additions are not yet released.
</Warning>

`Procedure` identifies a procedure independently of a package's allowance.
It contains `code`, localized `label`, `category` with its own `code` and
localized `label`, and `naturalSource`. Labels use the requested
[locales](/api/localization); a missing translation is `null`.

A hotel lists base Procedure objects without a `count` field.
[Package treatment items](/api/objects/treatment#procedure-allowance) add
`count` to these same fields. Use `code` to match the same procedure between
a hotel's offer and a visit type's treatment list.

```json
{
  "code": "carbon_dioxide_bath",
  "label": { "en": "Carbon dioxide bath" },
  "category": {
    "code": "hydrotherapy",
    "label": { "en": "Hydrotherapy" }
  },
  "naturalSource": "carbon_dioxide"
}
```

## Natural sources

`naturalSource` names the natural healing source a procedure uses, or is `null`
when it uses none.

| `naturalSource` | Meaning |
| --- | --- |
| `carbon_dioxide` | Natural carbon dioxide |
| `peat` | Peat |
| `mineral_water` | Natural mineral water |
