A price minimum describes one complete, buyable offer selected by the
[pricing rules](/api/prices). The same object appears in hotel prices,
package prices, package-at-hotel prices, and seasonal prices.

## Minimum fields

| Field | Meaning |
| --- | --- |
| `amount` | [`Money`](/api/currencies) amount of the offer after its promotions. |
| `original` | Amount of the same offer before its promotions, or `null` when no promotion lowers this minimum's rounded amount. |
| `nights` | Number of nights of the offer. |
| `occupancy` | Standard occupancy of the offer's room type. `perStay` amounts cover this many guests. |
| `hotel` | The offer's hotel: `id` and localized `name`. |
| `visitType` | The offer's visit type: `id` and localized `name`. |

A minimum identifies the hotel and package of the offer, not its room type or
arrival date. Display the amount together with its `nights` and `occupancy`.
Both names follow [Localization](/api/localization) and fall back to Czech.

The following minimum is a seven-night stay for one guest at EUR 504.00,
discounted from EUR 560.00:

```json
{
  "amount": {
    "amountMinor": 50400,
    "currency": "EUR",
    "currencyExponent": 2
  },
  "original": {
    "amountMinor": 56000,
    "currency": "EUR",
    "currencyExponent": 2
  },
  "nights": 7,
  "occupancy": 1,
  "hotel": {
    "id": "6720c0a1b2c3d4e5f6a7c101",
    "name": {
      "cs-CZ": "Hotel Pramen",
      "de": "Hotel Pramen"
    }
  },
  "visitType": {
    "id": "6720c0a1b2c3d4e5f6a7b801",
    "name": {
      "cs-CZ": "Klasická lázeňská léčba",
      "de": "Klassische Kur"
    }
  }
}
```

A non-null `original` is always greater than `amount`. Rounding applies to
each minimum separately: a small discount can produce an `original` on
`perStay` while `perPersonPerNight.original` stays `null`, because the
rounded average does not change.

## Pairs of minima

Prices are grouped by currency (`CZK`, `EUR`). A currency is present only when
it has a buyable offer. Each currency holds two independently selected minima:

| Minimum | Selection |
| --- | --- |
| `perPersonPerNight` | The lowest average price per guest per night. |
| `perStay` | The lowest total for the whole room and stay at its standard occupancy. |

The two minima can be different offers with different hotels, rooms, nights,
and occupancy. Never derive one from the other; see
[Two independent minima](/api/prices#two-independent-minima).

## Where minima appear

| Object | Path | Compared offers |
| --- | --- | --- |
| [Hotel](/api/objects/hotel) | `priceFrom.{currency}.all`, `.health`, `.wellness` | All packages the hotel sells, or one category. A category group is omitted when it has no buyable offer. |
| [Visit type](/api/objects/visit-type) | `priceFrom.{currency}` | The package at all its hotels. |
| Visit type hotel entry | `hotels[].priceFrom.{currency}` | The package at that hotel. |
| Visit type season | `hotels[].seasons[].priceFrom.{currency}` | Arrivals in that season at that hotel. |

A whole `priceFrom` is `null` when its scope has no buyable offer. For a
package this includes unavailable packages and packages booked on request. A
season without an offer stays listed with `priceFrom: null`.
