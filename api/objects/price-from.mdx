<Warning>
**Draft:** Capacity-independent `priceFrom` and its `perPersonPerStay`
minimum are not released yet.
</Warning>

A price minimum describes one complete stay selected by the
[pricing rules](/api/prices), without checking free rooms. A sold-out room
can set any minimum. The same object appears in hotel prices,
package prices, and package-at-hotel prices.
[Price periods](/api/objects/price-from-period) have their own price object.

## Minimum fields

| Field | Meaning |
| --- | --- |
| `amount` | [`Money`](/api/currencies) amount of the offer after its promotions. |
| `original` | Amount of the same offer before its promotions, or `null` when no promotion lowers this minimum's rounded amount. |
| `nights` | Number of nights of the offer. |
| `occupancy` | Standard occupancy of the offer's room type. `perStay` covers this many guests; per-person prices assume they share the room. |
| `hotel` | The offer's hotel: `id` and localized `name`. |
| `visitType` | The offer's visit type: `id` and localized `name`. |

A minimum identifies the hotel and package of the offer. It does not include
its room type, arrival date, or applied promotion ids. Display the amount
together with its `nights` and `occupancy`.
For example, `perPersonPerStay` with `occupancy: 2` is a price per guest
when two guests share the room. It is not the price for one guest occupying
the room alone. `occupancy` identifies the guest count, not a room category.

Both names follow [Localization](/api/localization) and fall back to Czech.

The following minimum is a seven-night stay for one guest at EUR 504.00,
discounted from EUR 560.00:

```json
{
  "amount": {
    "amountMinor": 50400,
    "currency": "EUR",
    "currencyExponent": 2
  },
  "original": {
    "amountMinor": 56000,
    "currency": "EUR",
    "currencyExponent": 2
  },
  "nights": 7,
  "occupancy": 1,
  "hotel": {
    "id": "6720c0a1b2c3d4e5f6a7c101",
    "name": {
      "cs-CZ": "Hotel Pramen",
      "de": "Hotel Pramen"
    }
  },
  "visitType": {
    "id": "6720c0a1b2c3d4e5f6a7b801",
    "name": {
      "cs-CZ": "Klasická lázeňská léčba",
      "de": "Klassische Kur"
    }
  }
}
```

A non-null `original` is always greater than `amount`. Rounding applies to
each minimum separately: a small discount can produce an `original` on
`perStay` while `perPersonPerNight.original` stays `null`, because the
rounded average does not change.

## Three minima

Prices are grouped by currency (`CZK`, `EUR`). A currency is present only when
a complete stay has a price in it. Each currency holds three independently
selected minima:

| Minimum | Selection |
| --- | --- |
| `perPersonPerNight` | The lowest average price per guest per night. |
| `perPersonPerStay` | The lowest price per guest for the whole stay, assuming standard room occupancy. |
| `perStay` | The lowest total for the whole room and stay at its standard occupancy. |

The three minima can be different offers with different hotels, rooms, nights,
and occupancy. Never derive one from another; see
[Three independent minima](/api/prices#three-independent-minima).

`perPersonPerStay` uses the same rounding as price periods: round the
whole-room total to minor units, divide by standard occupancy, and round
half up to a whole minor unit. Apply this separately to `amount` and
`original` of each candidate before comparing per-person stay prices.
Do not divide the already selected `perStay`: another room can have a
lower per-person price.

## Where minima appear

| Object | Path | Compared offers |
| --- | --- | --- |
| [Hotel](/api/objects/hotel) | `priceFrom.{currency}.all`, `.health`, `.wellness` | All packages the hotel sells, or one category. A category group is omitted when it has no complete stay. |
| [Visit type](/api/objects/visit-type) | `priceFrom.{currency}` | The package at all its hotels. |
| Visit type hotel listing | `hotelListings[].priceFrom.{currency}` | The package at that hotel. |

A whole `priceFrom` is `null` when no complete stay exists in its scope.
Visit type prices also cover packages booked on request and packages switched
off in SpaPortal (`unavailableReason: "disabled"`). Hotel prices include only
available packages with `bookingMode: "instant"`.
