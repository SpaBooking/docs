## Procedures

The proposed `procedures` array describes the hotel's procedure offer using
the shared [Procedure](/api/objects/procedure) object. It contains `code`,
localized `label`, `category`, and `naturalSource`, without a `count` field.
An empty array means no procedures are configured for the offer.

The hotel offer is independent of which procedures a particular stay
includes. See [Treatment behavior](/api/treatment#hotel-offer-and-package-inclusion)
for the distinction.

## Shared price minimum

The proposed price extension uses the
[shared Price from minimum](/api/objects/price-from) with both `hotel` and
`visitType` references. The hotel keeps its currency and category containers.
The calculation continues to follow the [pricing rules](/api/prices).
