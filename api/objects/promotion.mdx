title: "Promotion"
description: "A percentage discount on nights of a stay, and the hotels and room types it applies to."

A visit type's `promotions` lists its current and future promotions that apply
to the channel of your [public key](/api/authentication#channels-and-scope).
The API returns only applicable promotions; you do not filter them by channel.

A listed promotion does not guarantee a discounted stay: it can lie outside
the package's permitted stays, or the discounted rooms can be sold out. [Prices](/api/prices#promotions) explains how promotions change the
indicative minima and how overlapping discounts combine.

## Fields and night bounds

| Field | Meaning |
| --- | --- |
| `id` | Promotion id. Each promotion appears once, even when it is assigned to several channels. |
| `name` | Localized display name; a missing translation is `null`. |
| `percentage` | Discount in percent, greater than 0 and at most 100. |
| `from` | First discounted night. |
| `to` | Last discounted night, inclusive, or `null` when the promotion has no end. |
| `hotels` | Hotels and room types the promotion is limited to, or `null` when it applies to every hotel selling the package. |

A night is identified by the date it starts on: `to: "2027-02-28"` includes
the night of 28 February and its checkout on 1 March. These bounds describe
discounted nights, not the package's
[permitted stays](/api/visit-types#testing-a-stay-against-its-rules). A stay
that overlaps the promotion only partly is discounted on the overlapping
nights.

Each `hotels` entry has `hotelId` and `roomTypeIds`. `roomTypeIds: null` means
every room type of that hotel; otherwise it lists the eligible room type ids.
Entries reference only hotels that sell the package, and a detail request with
`hotelId` does not narrow them. A disabled room type can remain referenced,
but it is not offered for new bookings.

Promotions are ordered by `from`, then `id`.

## Example: selected room types of one hotel

This promotion discounts two room types of one hotel by 15 % on the nights
from 4 January to 28 February 2027. Other room types and hotels are
unaffected.

```json
{
  "id": "6720c0a1b2c3d4e5f6a7d302",
  "name": {
    "cs-CZ": "Zimní nabídka vybraných pokojů",
    "de": "Winterangebot für ausgewählte Zimmer"
  },
  "percentage": 15,
  "from": "2027-01-04",
  "to": "2027-02-28",
  "hotels": [
    {
      "hotelId": "6720c0a1b2c3d4e5f6a7c101",
      "roomTypeIds": [
        "6720c0a1b2c3d4e5f6a7f101",
        "6720c0a1b2c3d4e5f6a7f102"
      ]
    }
  ]
}
```
