---
title: "Localized string"
description: "A text value localized per response locale."
openapi-schema: "/api/v2/openapi.yaml LocalizedString"
---

A text value keyed by response locale (`cs-CZ`, `de`, `en`, `ru`). When
[`Accept-Language`](/api/localization) is set, only the matched keys are returned.
For most fields, a missing translation is returned as `null` under its
requested key. Hotel and price-from visit type names fall back to Czech;
automatically named room types can generate missing English and Russian names.
See [Missing translations](/api/localization#missing-translations) for the exceptions.

Image `alt` uses this object shape with additional fallback semantics and
preserves an explicitly empty string. See [Images](/api/images#alternative-text).
