title: "Room type"
description: "A category of room within a hotel."
openapi-schema: "/api/v2/openapi.yaml RoomType"
---

A category of room within a hotel — its localized category name, bed count,
free-text facilities, and images. Localized fields (`category`, `description`)
return the locale keys selected by [`Accept-Language`](/api/localization).

`hotel` is embedded only when the request sets `expand=hotel`.
