SpaPortal API price fields include an ISO 4217 currency code.

Supported currencies:

| Code | Currency |
| --- | --- |
| `CZK` | Czech koruna |
| `EUR` | Euro |

## Requesting currency

`POST /api/v2/calendar/dates/bulk` accepts `currency` when you want one or more
specific currencies. Send it in `shared` or in each item:

```json
{
  "shared": {
    "currency": "EUR,CZK"
  },
  "items": [
    {
      "key": "pawlik-superior",
      "hotelId": "65f...",
      "roomTypeId": "65f...",
      "dateFrom": "2026-04-01",
      "dateTo": "2026-04-04"
    }
  ]
}
```

Use a comma-separated list of supported currency codes. If `currency` is
omitted, the response includes all supported currencies.

## Money fields

Money fields use minor units:

```json
{
  "amountMinor": 1892400,
  "currency": "CZK",
  "currencyExponent": 2
}
```

`currencyExponent` tells you how many decimal places to apply. For both `CZK`
and `EUR`, the exponent is `2`, so `1892400` equals `18,924.00`.

Calendar date prices group their amounts by currency under `amounts`. When no
currency is requested, all supported currencies are returned:

```json
{
  "price": {
    "isFinal": true,
    "amounts": {
      "CZK": {
        "amountMinor": 180000,
        "currency": "CZK",
        "currencyExponent": 2
      },
      "EUR": {
        "amountMinor": 7200,
        "currency": "EUR",
        "currencyExponent": 2
      }
    }
  }
}
```

When one or more currencies are requested, `amounts` contains only those
currencies. If a requested currency has no amount, its value can be `null`.
