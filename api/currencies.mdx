SpaPortal API price fields include an ISO 4217 currency code.

Supported currencies:

| Code | Currency |
| --- | --- |
| `CZK` | Czech koruna |
| `EUR` | Euro |

## Money fields

Money fields use minor units:

```json
{
  "amountMinor": 1892400,
  "currency": "CZK",
  "currencyExponent": 2
}
```

`currencyExponent` tells you how many decimal places to apply. For both `CZK`
and `EUR`, the exponent is `2`, so `1892400` equals `18,924.00`.

Calendar date prices group their amounts by currency under `amounts` and return
every currency that has a price. A currency with no price for that date is
omitted.

```json
{
  "price": {
    "isFinal": true,
    "amounts": {
      "CZK": {
        "amountMinor": 180000,
        "currency": "CZK",
        "currencyExponent": 2
      },
      "EUR": {
        "amountMinor": 7200,
        "currency": "EUR",
        "currencyExponent": 2
      }
    }
  }
}
```
