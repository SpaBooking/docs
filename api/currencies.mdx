SpaPortal API price fields include an ISO 4217 currency code.

Supported currencies:

| Code | Currency |
| --- | --- |
| `CZK` | Czech koruna |
| `EUR` | Euro |

## Requesting currency

Endpoints that return prices accept `currency` when you want one or more
specific currencies:

```bash
GET /api/v2/room-types?currency=EUR,CZK
```

Use a comma-separated list of supported currency codes. If `currency` is
omitted, the API returns all supported currencies available for the requested
resource.

For `POST /api/v2/calendar/dates/bulk`, send `currency` in `shared` or in each
item:

```json
{
  "shared": {
    "currency": "EUR,CZK"
  },
  "items": [
    {
      "key": "pawlik-superior",
      "hotelId": "65f...",
      "roomTypeId": "65f...",
      "dateFrom": "2026-04-01",
      "dateTo": "2026-04-04"
    }
  ]
}
```

## Money fields

Money fields use minor units:

```json
{
  "amountMinor": 1892400,
  "currency": "CZK",
  "currencyExponent": 2
}
```

`currencyExponent` tells you how many decimal places to apply. For both `CZK`
and `EUR`, the exponent is `2`, so `1892400` equals `18,924.00`.

When no currency is requested, price fields are keyed by currency:

```json
{
  "lowestPrices": {
    "CZK": {
      "amountMinor": 180000,
      "currency": "CZK",
      "currencyExponent": 2
    },
    "EUR": {
      "amountMinor": 7200,
      "currency": "EUR",
      "currencyExponent": 2
    }
  }
}
```

When one or more currencies are requested, the response contains only those
currencies. If the resource exists but has no amount in a requested currency,
the value can be `null`.
