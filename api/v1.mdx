API v1 supports the complete booking flow. It remains necessary for endpoints
that API v2 does not yet replace, including visit types, final pricing, and
booking creation. This also applies to new booking integrations.

It exposes catalog, availability, pricing, and booking endpoints under:

```txt
https://spaportal.cz/api/v1
```
