---
title: "Search"
description: "Substring search across localized fields."
icon: "magnifying-glass"
---

Hotel, room type, and visit type lists accept a `search` query parameter for
text filtering.

```bash
GET /api/v2/room-types?search=superior
```

`search` matches a literal substring anywhere in a value: there are no search
operators, word stemming, or relevance ranking. Matching is case-insensitive
(`superior` matches `Superior`) and diacritics-insensitive (`lazne` matches
`Lázně`). A localized field is matched in every locale (`cs-CZ`, `de`, `en`,
`ru`) at once.

To match an exact value such as a room type code, use that field's own filter.

Each endpoint lists the field(s) its `search` covers. Hotel and
[visit type](/api/objects/visit-type) search match the localized name;
room-type search matches the single room name shared by all languages. See
[Room type names and labels](/api/objects/room-type#names-and-labels).
