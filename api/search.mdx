---
title: "Search"
description: "Substring search across localized fields."
icon: "magnifying-glass"
---

Hotel and room-type lists accept a `search` query parameter for text filtering.

```bash
GET /api/v2/room-types?search=superior
```

How `search` matches:

- **Literal substring** — matches the supplied text anywhere in a value. There
  are no search operators, word stemming, or relevance ranking.
- **Case-insensitive** — `superior` matches `Superior`.
- **Diacritics-insensitive** — `lazne` matches `Lázně`.
- **Localized fields** — matched against every locale (`cs-CZ`, `de`, `en`, `ru`)
  at once. Room type names are single text values shared by all languages.

To match an exact value such as a room type code, use that field's own filter.

Each endpoint lists the field(s) its `search` covers. Room-type search matches
the single room name. See [Room type names and labels](/api/objects/room-type#names-and-labels).
