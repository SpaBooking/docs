---
title: "Get a room type"
description: "Returns one room type by id."
---

```http
GET /api/v2/room-types/{roomTypeId}
```

## Path parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `roomTypeId` | string | Room type id. |

## Query parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `include` | string | Use `hotel` to include basic hotel data. |

## Example

```bash
curl \
  -H "X-SpaPortal-Public-Key: <public_key>" \
  -H "Accept-Language: cs-CZ,de-DE" \
  "https://spaportal.cz/api/v2/room-types/66f16191f739705faa020003?include=hotel"
```
