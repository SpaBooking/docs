---
title: "Get hotel room types"
description: "Returns room types for one hotel."
---

```http
GET /api/v2/hotels/{hotelId}/room-types
```

Returns room types for one hotel available to your distribution channel.

## Path parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `hotelId` | string | Hotel ObjectId. |

## Query parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `limit` | integer | Number of records to return. Default is `25`. Maximum is `100`. |
| `cursor` | string | Cursor from the previous page. |
| `visitTypeId` | string | Filter by visit type ObjectId. |
| `beds` | integer | Filter by number of beds. |
| `code` | string | Filter by room type code. |
| `search` | string | Search by localized category name. |
| `dateFrom` | date | Start date for availability and price context. |
| `dateTo` | date | End date. Must be after `dateFrom`. |
| `availableOnly` | boolean | Return only room types with availability in the supplied date range. Requires `dateFrom` and `dateTo`. |
| `currency` | string | Comma-separated currency list, for example `EUR,CZK`. |
| `include` | string | Use `hotel` to include basic hotel data. |
| `sort` | string | One of `createdAt:desc`, `createdAt:asc`, `id:asc`, `id:desc`. |

## Example

```bash
curl \
  -H "X-SpaPortal-Public-Key: <public_key>" \
  "https://spaportal.cz/api/v2/hotels/66f16191f739705faa020001/room-types?limit=25&currency=EUR"
```

## Response

The response shape is the same as [Get room types](/api/room-types/get-room-types).
