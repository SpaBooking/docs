The API uses a dedicated public key header:

```http
X-SpaPortal-Public-Key: <your_public_key>
```

Treat the public key as an opaque value.

## Channels and scope

A distribution channel is a sales context, such as a hotel's own website or
SpaBooking. Each channel has its own public key. A key identifies one specific
channel and scopes requests to the active companies connected to it; one key
can cover more than one company.

Resources and channel-specific content are resolved within this scope.
Promotions and their effect on prices depend on the requesting channel, and a
visit type's [`channelContent.collections`](/api/objects/visit-type#channel-content)
is filled only for the key of the company's own website. A response for one key
must not be reused for another key. Include the public-key context in your
cache partitioning without exposing the key in a public cache identifier.

A promotion can apply to several channels. The API returns only those
applicable to your key, so clients do not need to filter them by channel.

## Getting your public key

To find your public key: `Administration → Distribution Channel → [your channel] → Channel detail → Public keys`

## Authentication errors

| Status | Error code | Cause |
| --: | --- | --- |
| `400` | `missing_authentication` | The key is missing. |
| `401` | `invalid_authentication` | The key is invalid. |

Authentication runs before input validation. A request with both a missing key
and invalid parameters returns the authentication error.
