---
title: "Sorting"
description: "Order list results with the sort parameter."

---

Hotel and room-type lists accept a `sort` query parameter as `<field>:<direction>`, where
direction is `asc` or `desc`.

<Note>
  **Draft — room types:** The room-type examples on this page use the
  draft [room-type contract](/api/objects/room-type).
</Note>

```bash
GET /api/v2/room-types?sort=createdAt:desc
```

- Supported values are `createdAt:desc` (default) and `createdAt:asc`.
- These orders use the unique record `id`, descending or ascending. IDs generally
  follow creation order; this is not a separate sort on a timestamp field.
- Keep the same sort and filters while paging. Cursors do not freeze a snapshot
  of the data: additions, removals, or edits between requests can change results.
- Server-side sorting by price, name, or relevance is not supported.
