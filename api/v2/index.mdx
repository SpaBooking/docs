title: "API v2"
description: "Future SpaPortal API version."
icon: "square-terminal"
---

API v2 is reserved for new endpoints and breaking improvements.

The first documented endpoint is `POST /calendar/dates/bulk`. It batches multiple calendar date lookups into one request.

Use API v1 for all current production integrations unless a SpaPortal administrator tells you to adopt a v2 endpoint.
