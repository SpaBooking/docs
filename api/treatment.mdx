Use the [Treatment object](/api/objects/treatment) to describe what a package
includes, and the [Procedure object](/api/objects/procedure) to identify a
procedure consistently across the hotel and package. The object pages own
the field definitions, selection modes, and code lists.

## Examinations depend on stay length

An examination with a minimum-night threshold is included only when the
selected stay reaches that length. For example, an interim examination with
a threshold of 14 nights is included in a 14-night stay but not a seven-night
stay. Apply each examination's threshold independently.

## Allowances and fixed lists

An overall allowance and a fixed procedure list describe different facts.
For example, a package can offer 15 procedures per week and also specify a
fixed list with six carbon dioxide baths and four peat wraps for the whole
stay.

Show the overall allowance with its unit and the fixed list with its own
counts. Do not multiply those item counts by the number of weeks or force
their sum to equal the overall allowance. The API returns the configured
allowance and list independently.

When procedures are selected from the hotel's offer, an empty package item
list does not mean that treatment is absent. The hotel supplies the choices.
When the package supplies a choice list, the entries describe the choices
rather than a promise that every listed procedure will be provided.

## Hotel offer and package inclusion

The hotel's procedure offer describes services the property provides. It does
not say which ones are included in a particular stay. Use the package's
Treatment to determine inclusion and its selection mode. The proposed
[Hotel procedures](/api/objects/hotel#procedures) and Treatment items share
Procedure identities, so clients can join them by code.
