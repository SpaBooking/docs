The API reference describes the public SpaPortal API contract.

Use it when you need exact request formats, authentication rules, response
shapes, error behavior, date formats, currencies, and endpoint details.

## Default version

API v2 is the default reference direction for new public API design.

<Warning>
  API v2 is still in progress. Use API v1 for production integrations unless a
  SpaPortal administrator tells you to use a v2 endpoint.
</Warning>

## Base URLs

Use the production API for live traffic:

```txt
https://spaportal.cz/api/v2
```

Use the staging API for integration testing:

```txt
https://staging.spaportal.cz/api/v2
```

API v1 remains available under the same hosts:

```txt
https://spaportal.cz/api/v1
https://staging.spaportal.cz/api/v1
```

## Endpoint reference

The generated endpoint reference is split by API version.

Start with [API v2](/api/v2) for new contracts. Use [API v1](/api/v1) for
current production integrations.
