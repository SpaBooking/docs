Learn the conventions, authentication, and pagination patterns used across the SpaPortal API.

## Conventions

The base URL to send all API requests is `https://spaportal.cz/api/`. The SpaPortal API follows RESTful conventions when possible, with most operations performed via `GET`, `POST`, `PATCH`, and `DELETE` requests. Request and response bodies are encoded as JSON.

- HTTPS only
- JSON bodies for `POST` — send `Content-Type: application/json`
- Query parameters for `GET` filters

## Paths and field names

API paths are versioned:

```txt
https://spaportal.cz/api/v2
```

Resource paths use plural nouns: `/hotels`, `/visit-types`, `/calendar/dates`.

## IDs

- **v1** — legacy numeric `id`; some objects also expose `_id` (references v2 id)
- **v2** — ObjectId string as `id` (24-character hex); no legacy numeric IDs

## Dates and time

Calendar dates and times use ISO 8601. Exact timestamps (e.g. `createdAt`, `updatedAt`) use millisecond precision, always in UTC, denoted by the `Z` suffix:

- **Date** - `2026-04-01`
- **Time** - `2026-04-01T10:15:30.000Z`

## Currencies

Supported currencies: `CZK` (Czech koruna) and `EUR` (Euro).

Money values use the smallest currency unit. `currencyExponent` tells you how many decimal places to apply — for both `CZK` and `EUR` that is `2`, so `1892400` equals `18,924.00`.

```json
{ "amountMinor": 1892400, "currency": "CZK", "currencyExponent": 2 }
```

## Images and thumbnails

Some entities, such as hotels, room types, and visit types, can include image URLs.

- `image` points to the original image.
- `thumbnail` points to a smaller generated image for previews and lists.

Both fields can be `null` when an image is not available.

```json
{
  "image": "https://spaportal-files.s3.eu-central-1.amazonaws.com/production/hotels/example/pawlik.jpg",
  "thumbnail": "https://spaportal-files.s3.eu-central-1.amazonaws.com/production/thumbnails/hotels/example/pawlik.webp"
}
```

## Localization

Set `Accept-Language` header to request specific languages.

```bash
-H "Accept-Language: cs_CZ,de"
```

 Localized fields are returned as objects keyed by language code.

```json
{ "name": { "cs_CZ": "Frantiskovy Lazne", "de": "Franzensbad" } }
```

The language code uses BCP 47 tags (`cs-CZ`, `de`, `en`, `ru`).

When `Accept-Language` header is omitted, API returns all supported language keys.

## Pagination

SpaPortal API uses cursor pagination:

```json
{
  "data": [],
  "pagination": { "nextCursor": "...", "hasMore": true, "total": 42 }
}
```

Pass `cursor` in GET parameters from the previous response to fetch the next page.
