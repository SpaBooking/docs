SpaPortal API uses API keys.

Send the key as a bearer token in the `Authorization` header:

```bash
curl \
  -H "Authorization: Bearer <API_KEY>" \
  "https://spaportal.cz/api/v1/destinations"
```

You can also send the key as the `access_token` query parameter:

```bash
curl "https://spaportal.cz/api/v1/destinations?access_token=<API_KEY>"
```

Prefer the header form for new integrations.

## Errors

If the key is missing, SpaPortal returns `400`.

If the key is invalid, SpaPortal returns `401`.

If the `Authorization` header does not use `Bearer <API_KEY>`, SpaPortal returns `400`.
