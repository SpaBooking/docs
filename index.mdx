## API versions

API v1 is the current public API. It is used by booking clients such as SpaBooking.cz, SpaBooking.de, and FrantiskovyLazne.cz.

API v2 is the default direction for new public API design. The first documented
v2 endpoint is the bulk calendar dates endpoint. The [API v2 design
proposal](/api/v2/design) describes the target contract.

## Base URLs

Use the production API for live traffic:

```txt
https://spaportal.cz/api/v1
```

Use the staging API for integration testing:

```txt
https://staging.spaportal.cz/api/v1
```
